# Politique de sécurité

backup365 manipule des sauvegardes Microsoft 365, donc des données personnelles : une faille
est prise au sérieux.

## Signaler une faille

**Ne publiez pas la faille dans une issue, une discussion ou une PR.** Utilisez le signalement
privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability** (GitHub Security
Advisories). Seuls les mainteneurs voient le signalement.

Indiquez la version ou le commit, les étapes pour reproduire et l'impact. N'y joignez **aucune
donnée réelle** (tenant, adresses, contenus de mails) : un exemple synthétique suffit.

## Suite donnée

Le projet est en phase MVP, mené par un mainteneur : accusé de réception et corrections au mieux,
sans délai garanti. Une faille confirmée est corrigée puis publiée sous forme d'avis de sécurité,
avec mention du signalement si vous le souhaitez.

## Périmètre

Ce dépôt (console, serveur, installation compose). Une faille du moteur doit être signalée à
[Atlas](https://github.com/wisecom-oy/atlas) ; en cas de doute, signalez-la ici.
